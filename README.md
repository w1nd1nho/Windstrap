# 🎐 Windstrap – FFlag Injector for Roblox

**Windstrap** is a clean, powerful, and modern FFlag injector for Roblox.  
It lets you modify Roblox’s internal FFlags (FastFlags) in real‑time using a beautiful, user‑friendly GUI.

> No Discord RPC, no preset packs – just a clean, fast, and customisable tool.

---

## ✨ Features

- **🔥 Two Injection Methods**  
  - **Offsetless Injection** – finds flags by hashing their names (no need for offsets).  
  - **Singleton Injection** – uses Roblox’s internal flag table (more reliable and future‑proof).  
- **🎨 Full Custom Theme** – pick your own colours for background, accent, text, sidebar, and cards.  
- **🛡️ Stealth & Protection**  
  - Safe Mode (NtWrite + XOR encryption)  
  - Randomised writes and timing attacks to avoid detection  
  - Auto‑reapply flags if they get reset  
  - Stealth Mode – hides the window when recording software is running  
- **📦 Batch Injection** – split large flag lists into batches with custom delays to reduce crashes.  
- **📂 Import / Export** – load and save flag lists as JSON.  
- **📋 Built‑in Preset Library** – browse and add flags from a fetched offset list.  
- **🖥️ Terminal Log** – see real‑time injection logs and errors.  
- **🎛️ Roblox Engine Tweaks** – adjust graphics, FPS, transparency, reduced motion, font size, and mouse sensitivity directly from the GUI.  
- **🔑 Hide/Show Hotkey** – default `Insert` – instantly hide the window.
